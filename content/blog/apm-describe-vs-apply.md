You can know every model on the APM syllabus and still write an answer that scores almost nothing.

That's the trap.

APM is not asking whether you remember the Building Block Model, the Performance Pyramid, Fitzgerald and Moon, target costing, EVA, benchmarking or the balanced scorecard.

It's asking whether you can use the model to say something useful about the business in front of you.

The model is not the answer.

The scenario is the answer.

The model only earns marks when it helps you explain the scenario better.

## Describe-only: the paragraph that scores almost nothing

Asked how the Building Block Model could help a struggling service business, a describe-only answer might read like this:

> The Building Block Model has three levels: dimensions, standards, and rewards. Dimensions are the areas of performance measured, such as quality and flexibility. Standards should be owned, achievable, and fair. Rewards should be clear, motivating, and controllable.

Every sentence is true.

That's the problem. It sounds safe because it's correct.

But it hasn't done anything with the case.

There is no business problem. No customer issue. No staff behaviour. No judgement. Just a model being described beside a scenario.

A marker looking for application has very little to reward.

## Applied: the same model, earning the marks

Now use the same model properly:

> For this business, the key dimensions should be responsiveness and service quality, because customers are leaving after repeated delays. Measuring cost alone would miss the real performance problem.
>
> The standards are also weak. Staff had no input into the current targets, so the targets are unlikely to be owned or seen as fair. That helps explain why teams are gaming the measures instead of improving service.
>
> I'd fix the standards and reward link before adding more KPIs, because more measures won't solve a target system staff don't trust.

Same model.

Different answer.

The first paragraph tells the marker what the model is.

The second paragraph uses the model to explain what is going wrong.

That's APM.

## The three moves that earn marks

An applied APM paragraph usually does three things.

### 1. It links to the scenario

Not:

> Standards should be fair.

But:

> The targets are unlikely to be seen as fair because staff had no input into them.

That's a scenario link.

You've taken the model and attached it to a fact from the case.

### 2. It names a limitation or problem

Not:

> Rewards should be motivating.

But:

> The reward system may be encouraging staff to game the target rather than improve service.

That shows analysis. You're not presenting the model as a tidy theory. You're using it to diagnose a weakness.

### 3. It makes a judgement

Not:

> The business should use dimensions, standards and rewards.

But:

> Fix the standards and reward link before adding more KPIs.

That's judgement.

APM rewards that because managers don't need a list of everything in the model. They need to know what matters most.

## The exam mistake

Students think the model proves knowledge.

It doesn't.

A model only helps if it changes the quality of your answer.

If your paragraph would still make sense with the company name removed, it probably isn't applied enough.

That's the test.

Read your paragraph back and ask:

> Could this answer fit almost any company?

If yes, you've probably described.

APM needs you to apply.
